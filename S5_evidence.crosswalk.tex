\section*{Identifier architecture}
The review distinguishes records (\texttt{REC}), bibliographic reports (\texttt{REP}), underlying studies (\texttt{STU}), algorithm entities (\texttt{ALG}) and experiments (\texttt{EXP}). RP1--RP62 are stable study-level aliases. The historical catalogue supplies stable \texttt{ALG} identifiers. The original record-level search export and experiment-level extraction file were not present in the supplied archive; those links are therefore reported as unavailable rather than fabricated.

\paragraph{Deduplication rule.}
Multiple database records that resolve to the same bibliographic report should link to one \texttt{REP}. Multiple reports describing one underlying investigation should link to one \texttt{STU}. An \texttt{ALG} entity is created only when a primary source supports a first-level optimizer or substantively distinct framework. Acronym equality alone is never used as a merge criterion. Independent benchmark configurations receive separate \texttt{EXP} identifiers only when the experiment-level source data are available.
