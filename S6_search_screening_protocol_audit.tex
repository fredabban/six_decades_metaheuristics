\section*{Protocol status}
The review window is 1 January 1965 through 31 December 2025. The protocol was not prospectively registered. The supplied source package does not contain the original database-export timestamps or complete paired screening decisions. No retrospective execution dates, disagreements, or reliability coefficients are created.

\section*{Screening decision schema}
A reproducible screening ledger requires the fields
\begin{quote}\small
\texttt{record\_id, report\_id, database, title, doi, screener1\_decision, screener2\_decision, disagreement, adjudicated\_decision, primary\_exclusion\_code, secondary\_code, reviewer\_role, decision\_date}.
\end{quote}
If a stage was screened by one reviewer, that fact should be encoded directly. Cohen's $\kappa$ or percentage agreement is reportable only for genuinely paired independent decisions. The supplied source package does not support a retrospective $\kappa$ calculation.

\section*{Protocol deviations and source-specific PRISMA counts}
The manuscript provides the harmonized search strings and aggregate PRISMA arithmetic but not the original database-export timestamps or a source-by-source decomposition summing to 4,696. Accordingly, this supplement does not reuse older, inconsistent 4,695-record figures from prior drafts. The latest manuscript values above control the supplementary package.
